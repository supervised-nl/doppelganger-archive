# Home and site chrome

Mode: Persuade on home. Read on spec and structure. How-to on load.

Audience: a writer who wants any AI to sound like them. Job: understand the file and load it in seconds.

Primary action: Download example and Copy starter prompt. Proof: the Mara Ellison example file at DOPPELGANGER.md, plus the measured drawing generated from SECTIONS.

Constraints: payload-guide materials. Dark default via html.dark on true black. Light html via persisted header switch. No accent color. Archivo and JetBrains Mono, self-hosted. Radius 0. Solid header. Mobile-first 390 then 1280. Structure SVG visible at every width. No AGENTS.md on home or load. No Supervised or Jeroen. No generator. No nested cards. No zinc HSL 240 tokens. No DM Sans. No b2YPlg.

## Direction contract

THESIS: The filename is the product. The first viewport is a payload guide, not a docs wiki and not a green marketing page. Refuse sticky cards, Why essays, and AGENTS.md comparisons.

OWN-WORLD: True-black ground by default, paper one switch away. Hairlines only. Archivo at display width 112. JetBrains Mono for data. Radius 0. Header is a solid strip with a 44px theme toggle. The home drawing is the file.

STORY: Visitor reads the filename, one sentence, a short why, and two primary actions. They see the six MUST sections as a drawing. They download the example or copy the starter prompt. Load-guide detail stays below.

FIRST VIEWPORT at 390: skip link, wordmark, sun theme toggle (44px), Menu (44px). Then H1 DOPPELGANGER.md. One lede sentence. One short why. Two ink-on-ground buttons: Download example, Copy starter prompt. Then the compact structure SVG with names in the bands. At 1280 the same axis, more air, horizontal mono nav, wide SVG with leaders and roles.

FORM: payload user guide. Brief-pinned. Fingerprint mark only on favicon, apple-touch, and OG.
