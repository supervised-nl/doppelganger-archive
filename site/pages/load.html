How to load

The portable story is paste, attach, or @ the file. There is no hosted loader. If a box has a character cap, paste a short excerpt and attach the full file where the tool allows it.

A short excerpt that still works is Meta, Tone rules, Hard bans, and Safety. Prefer the full file when you can.

ChatGPT

  1. Create a Project for the writing work.
  2. Attach DOPPELGANGER.md as a project file.
  3. In project instructions, add: "Write user-facing copy in the voice of the attached DOPPELGANGER.md. Follow Hard bans and Safety. Do not invent facts."

Custom instructions apply to every chat. Free and Go accounts cap custom instructions at 1,500 characters. Plus, Pro, Enterprise, Business, and Education accounts cap them at 5,000 characters. If you use custom instructions, paste the short excerpt, not the whole file. A Project file is the better default.

Claude

  1. Open a Project and upload DOPPELGANGER.md to project knowledge.
  2. In project instructions, tell Claude to write user-facing copy from that file and to obey Hard bans and Safety.

For repeat use across projects, add a Skill whose SKILL.md says to load DOPPELGANGER.md before writing copy. In Claude Code, attach the file with @DOPPELGANGER.md.

Gemini

  1. Create a Gem, or open a chat where you write as this voice.
  2. Attach DOPPELGANGER.md as a knowledge file, or paste it at the top of the first message.
  3. Tell Gemini to follow the file, including Hard bans and Safety.

In Gemini CLI or in Cursor, attach the file with @DOPPELGANGER.md.

Cursor

  1. Keep DOPPELGANGER.md in the repo or in the workspace.
  2. In the chat, attach it with @DOPPELGANGER.md.
  3. Optional: add one line to AGENTS.md: "Before writing user-facing copy, read DOPPELGANGER.md."

Claude Code uses the same @DOPPELGANGER.md attach. Do not fold the whole voice file into AGENTS.md. Coding instructions and writing voice stay in separate files.

Paste anywhere

  1. Open DOPPELGANGER.md.
  2. Copy the full file.
  3. Paste it at the top of a new chat.
  4. Add one line: "Write as this voice. Follow Hard bans and Safety."

If the composer converts a long paste into an attachment, leave it attached. That is still a load.
