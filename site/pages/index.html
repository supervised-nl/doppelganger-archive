DOPPELGANGER.md

DOPPELGANGER.md is the AGENTS.md of a person or company. It is one open Markdown file that teaches any AI to write in your voice, not generic AI slop.

Keep the file next to AGENTS.md, or anywhere you write. Paste it, attach it, or @DOPPELGANGER.md. There is no account, no upload API, and no hosted loader.

What

A DOPPELGANGER.md file is a short English Markdown document. It names the speaker, shows 3 to 7 real writing samples, lists tone rules and hard bans, and forbids secrets and invented facts.

Any model that can read a file can use it. ChatGPT, Claude, Gemini, Cursor, and a paste into a new chat all work.

Why

Coding agents already have a well-known file. Writing does not. Models default to the same smooth, hedged register. Samples, tone rules, and an explicit ban list break that default without a brand kit.

What it is not

  • Not AGENTS.md. That file tells a coding agent how to work in a repo.
  • Not BRAND.md or Brand Context Protocol. Those cover strategy, voice, and visual identity.
  • Not a design system, a logo, or a color palette.
  • Not a generator and not a loader you upload to.

Read the structure, then load the file in your tools. The specification is the source of truth. One fictional example shows the format.
