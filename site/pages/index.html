How to load

  1. Write a DOPPELGANGER.md. Copy the example, then swap in your samples, rules, and bans.
  2. Paste it, attach it, or @ it in ChatGPT, Claude, Gemini, Cursor, or any chat.
  3. Ask for the draft. Add one line: "Write as this voice. Follow Hard bans and Safety."

For agents

Fetch https://doppelganger.md/DOPPELGANGER.md (on this site: DOPPELGANGER.md) and write it to DOPPELGANGER.md in the project root, or the path the user names. Optional: fetch https://doppelganger.md/SPEC.md when authoring a new voice file. Then instruct with the starter prompt.
