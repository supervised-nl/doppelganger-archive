Structure

A conformant DOPPELGANGER.md file uses these section titles. The levels follow RFC 2119. The specification is the source of truth. This table is a map, not a second spec.

{{SECTIONS_TABLE}}

Put MUST sections in that order. Add SHOULD sections after Safety when you have them. A short How to use pointer is enough for MAY. Do not add visual identity, coding conventions, or secrets.

Mark the file with doppelganger-spec: 0.1 in YAML frontmatter or in an HTML comment. That marker is the spec version. The Meta version field is semver for the voice content.

Start from the example, or write the sections from this table and check them against the spec.
