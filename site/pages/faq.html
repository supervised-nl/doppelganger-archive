FAQ

How is this different from AGENTS.md?

AGENTS.md is a README for coding agents. It holds build commands, test commands, and repo conventions. DOPPELGANGER.md is a voice file. It holds samples, tone rules, and bans for writing. Keep both. Point AGENTS.md at the voice file when the agent writes user-facing copy.

How is this different from BRAND.md?

BRAND.md is an open brand-identity file. It covers strategy, voice, and visual primitives such as color and type. Brand Context Protocol is a larger, discoverable brand tree. DOPPELGANGER.md is thinner. Voice only. No logo rules, no palette, no layout system.

How is this different from COPY.md?

COPY.md is a related practice: voice notes plus a banned-phrase list. DOPPELGANGER.md is the named spec. It has a marker, MUST and SHOULD sections, a safety rule against invented facts, and a load guide that does not depend on one vendor.

Why is there no hosted loader or generator?

A hosted loader would become an account, an API, and a lock-in. The convention is the file. Paste it, attach it, or @ it. That works in every tool on this site and in tools that do not exist yet.

Can the file hold secrets?

No. The spec forbids API keys, passwords, session tokens, and unpublished personal data. It also forbids invented facts, metrics, and clients. If a claim is not in the file and not in the prompt, the model must not fill the gap.

Person or company?

Meta kind is person or organization. The sections are the same. An organization file speaks as the company, not as a staff roster.

Which language?

Spec 0.1 is English only. The Meta language field is a BCP 47 tag. Use en for 0.1.

What is the license?

The specification, the example, and the pages on this site are dedicated to the public domain under CC0 1.0. Your own DOPPELGANGER.md can use another license. Meta must name it.

Where is the canonical site?

The canonical name is doppelganger.md. Until DNS points here, serve the docs/ folder on GitHub Pages or preview it locally with node scripts/site.mjs preview.
